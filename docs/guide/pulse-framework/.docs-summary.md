## 🎯 Key Concepts Covered

### Reactivity System
- **Signals**: Reactive variables that notify dependents
- **Computed**: Lazily-evaluated derived values
- **Effects**: Side effects that run when dependencies change
- **Auto-tracking**: No manual dependency arrays needed

### Component Model
- **`Pulse.Fn`**: TypeScript type for function components
- **Real DOM**: Components return actual HTMLElements
- **No re-renders**: Fine-grained updates only
- **JSX syntax**: Familiar declarative syntax

### Philosophy
- **DOM-first**: Work with real DOM, not virtual
- **Fine-grained**: Update only what changed
- **Simple API**: No hooks, no complex rules
- **Predictable**: No magic, easy to debug
