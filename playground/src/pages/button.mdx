# Button Component

Un composant bouton polyvalent avec plusieurs variantes, tailles, états de chargement et icônes.

## Exemple de Base

<div id="demo-basic"></div>

<script type="module">
  import Pulse from 'pulse-framework';
  import { Button } from '@odyssee/components';

  const btn = Button({
    variant: "solid",
    color: "primary",
    children: "Click me"
  });

  document.getElementById('demo-basic').appendChild(btn);
</script>

**Code:**
```tsx
const btn = Button({
  variant: "solid",
  color: "primary",
  children: "Click me"
});
```

## Compteur Interactif

<div id="demo-counter" class="demo-section">
  <div class="demo-output" id="counter-output">Count: 0</div>
  <div class="demo-grid"></div>
</div>

<script type="module">
  import Pulse from 'pulse-framework';
  import { Button } from '@odyssee/components';

  const count = Pulse.signal(0);
  const output = document.getElementById('counter-output');
  const container = document.querySelector('#demo-counter .demo-grid');

  const incrementBtn = Button({
    color: "success",
    onClick: () => {
      count(count() + 1);
      output.textContent = 'Count: ' + count();
    },
    children: "Increment"
  });

  const decrementBtn = Button({
    color: "danger",
    variant: "outline",
    onClick: () => {
      count(count() - 1);
      output.textContent = 'Count: ' + count();
    },
    children: "Decrement"
  });

  const resetBtn = Button({
    variant: "ghost",
    onClick: () => {
      count(0);
      output.textContent = 'Count: ' + count();
    },
    children: "Reset"
  });

  container.appendChild(incrementBtn);
  container.appendChild(decrementBtn);
  container.appendChild(resetBtn);
</script>

**Code:**
```tsx
const count = Pulse.signal(0);

const btn = Button({
  onClick: () => {
    count(count() + 1);
    console.log('Count:', count());
  },
  children: "Increment"
});
```

## État de Chargement

<div id="demo-loading" class="demo-section">
  <div class="demo-output" id="loading-output">Cliquez pour démarrer</div>
  <div class="demo-grid"></div>
</div>

<script type="module">
  import Pulse from 'pulse-framework';
  import { Button } from '@odyssee/components';

  const isLoading = Pulse.signal(false);
  const output = document.getElementById('loading-output');
  const container = document.querySelector('#demo-loading .demo-grid');

  const loadingBtn = Button({
    color: "primary",
    loading: isLoading,
    onClick: async () => {
      isLoading(true);
      output.textContent = '⏳ Chargement...';
      
      await new Promise(resolve => setTimeout(resolve, 2000));
      
      isLoading(false);
      output.textContent = '✅ Terminé ! Cliquez à nouveau.';
    },
    children: "Démarrer le chargement"
  });

  container.appendChild(loadingBtn);
</script>

**Code:**
```tsx
const isLoading = Pulse.signal(false);

const btn = Button({
  loading: isLoading,
  onClick: async () => {
    isLoading(true);
    await someAsyncOperation();
    isLoading(false);
  },
  children: "Submit"
});
```

## Props

| Prop | Type | Défaut | Description |
|------|------|--------|-------------|
| variant | "solid" \| "outline" \| "ghost" \| "soft" \| "link" | "solid" | Style du bouton |
| color | "primary" \| "secondary" \| "success" \| "danger" \| "warning" \| "info" | "primary" | Couleur |
| size | "xs" \| "sm" \| "md" \| "lg" \| "xl" | "md" | Taille |
| disabled | boolean \| Signal | false | Désactiver |
| loading | boolean \| Signal | false | État de chargement |
| icon | string | - | Icône à afficher |
| iconPosition | "left" \| "right" | "left" | Position de l'icône |
| fullWidth | boolean | false | Pleine largeur |
| onClick | (event: Event) => void | - | Gestionnaire de clic |
| children | string \| HTMLElement | - | Contenu du bouton |

## Utilisation de Base

```tsx
import { Button } from '@odyssee/components';

const btn = Button({
  variant: "solid",
  color: "primary",
  children: "Cliquez-moi"
});

document.getElementById('app').appendChild(btn);
```

## Avec État Réactif

```tsx
import { Button, Pulse } from '@odyssee/components';

const count = Pulse.signal(0);

});
```
