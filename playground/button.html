Button Component

Un composant bouton polyvalent avec plusieurs variantes, tailles, états de chargement et icônes.

Exemple de Base

Un simple bouton avec le style par défaut

const btn = Button({ variant: "solid", color: "primary", children: "Click me" });

Variantes

Cinq styles différents : solid, outline, ghost, soft, et link

Button({ variant: "solid", children: "Solid" }) Button({ variant: "outline", children: "Outline" }) Button({ variant: "ghost", children: "Ghost" }) Button({ variant: "soft", children: "Soft" }) Button({ variant: "link", children: "Link" })

Couleurs

Huit couleurs disponibles pour différents contextes

Button({ color: "primary", children: "Primary" }) Button({ color: "success", children: "Success" }) Button({ color: "danger", children: "Danger" }) Button({ color: "warning", children: "Warning" })

Tailles

Cinq tailles de xs à xl

Button({ size: "xs", children: "XS" }) Button({ size: "sm", children: "SM" }) Button({ size: "md", children: "MD" }) Button({ size: "lg", children: "LG" }) Button({ size: "xl", children: "XL" })

Avec Icônes

Ajouter des icônes à gauche ou à droite

Button({ icon: "🚀", iconPosition: "left", children: "Launch" }) Button({ icon: "→", iconPosition: "right", children: "Next" }) Button({ icon: "❤️", color: "danger", variant: "soft" })

Compteur Interactif

Exemple avec Pulse signals pour la réactivité

Count: 0
const count = Pulse.signal(0); const btn = Button({ onClick: () => { count(count() + 1); console.log('Count:', count()); }, children: "Increment" });

État de Chargement

Afficher un spinner pendant les opérations asynchrones

Cliquez pour démarrer
const isLoading = Pulse.signal(false); const btn = Button({ loading: isLoading, onClick: async () => { isLoading(true); await someAsyncOperation(); isLoading(false); }, children: "Submit" });

Props

Prop Type Défaut Description
variant "solid" | "outline" | "ghost" | "soft" | "link" "solid" Style du bouton
color "primary" | "secondary" | "success" | "danger" | "warning" | "info" "primary" Couleur du bouton
size "xs" | "sm" | "md" | "lg" | "xl" "md" Taille du bouton
disabled boolean | Signal<boolean> false Désactiver le bouton
loading boolean | Signal<boolean> false Afficher l'état de chargement
icon string - Icône à afficher
iconPosition "left" | "right" "left" Position de l'icône
fullWidth boolean false Bouton pleine largeur
onClick (event: Event) => void - Gestionnaire de clic
children string | HTMLElement - Contenu du bouton
